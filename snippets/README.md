# Fragmentos de código

Reescritos a partir del proyecto para ilustrar las ideas. Están **simplificados y son genéricos**: no son el código de producción ni compilan como proyecto por sí solos.

| Fichero | Qué muestra |
|---|---|
| [01-cola-sin-conexion.ts](01-cola-sin-conexion.ts) | Navegador: cola en IndexedDB y cifrado del PIN con la clave pública del servidor (WebCrypto) |
| [02-sincronizar-marca.ts](02-sincronizar-marca.ts) | Servidor: abrir el «sobre», corregir el desfase de reloj, idempotencia y reglas anti-abuso del panel |
| [03-registro-inalterable.sql](03-registro-inalterable.sql) | PostgreSQL: tablas solo-inserción y cadena de hashes por persona |
| [04-intervalos.ts](04-intervalos.ts) | Aritmética de intervalos para el cómputo (minutos nocturnos en turnos que cruzan medianoche) |
| [05-saldo-bolsa.ts](05-saldo-bolsa.ts) | Saldo de la bolsa de horas calculado, no almacenado |
